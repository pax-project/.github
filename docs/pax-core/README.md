# pax-core docs

Everything the [`pax-core`](https://github.com/pax-project/pax-core) repo
itself doesn't hold — its spec, current implementation status, and
not-yet-built ideas — lives here instead, so the code repo's own docs never
describe a moving target.

- [`ideas.md`](ideas.md) — feature idea backlog (6 ideas): mostly "another
  client of the library" or "another provider capability."
- [`mvp.md`](mvp.md) — the original, pre-implementation MVP spec.
  Historical: kept as written, not updated as things ship.
- [`status.md`](status.md) — current implementation status against that
  spec. Kept up to date; this is the one to check for "is X built yet."
