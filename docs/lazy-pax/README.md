# lazy-pax docs

Everything the [`lazy-pax`](https://github.com/pax-project/lazy-pax) repo
itself doesn't hold — its spec, current implementation status, build
history, and not-yet-built ideas — lives here instead, so the code repo's
own docs never describe a moving target.

- [`ideas.md`](ideas.md) — feature idea backlog (5 ideas): UI-level features
  and the one idea that stays a plain heuristic rather than routing through
  `pax-ai` (see [`../README.md`](../README.md) for that split).
- [`dod.md`](dod.md) — the original Definition of Done for the `lazypax`
  MVP. Historical, same role as `pax-core`'s `mvp.md`.
- [`status.md`](status.md) — current implementation status against that
  DoD. Kept up to date.
- [`build-log.md`](build-log.md) — step-by-step history of how the MVP was
  built (bugs found, verification detail per step). Purely historical, not
  a status checklist.
