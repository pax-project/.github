# .github

Org-wide community-health defaults and cross-cutting docs for the
`pax-project` organization — not a project repo itself.

- The organization's profile page (what renders at
  [github.com/pax-project](https://github.com/pax-project)) is
  [`profile/README.md`](profile/README.md).
- Fixed architectural boundaries that don't fit an Issue/Discussion/Project
  (non-goals, resolved decisions) live in [`docs/`](docs/README.md).
  Idea backlogs and implementation status live in each repo's Issues (or
  Discussions, for `pax-ai`) and the shared org-wide Project instead.
