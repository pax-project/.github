# .github

Org-wide community-health defaults and cross-cutting docs for the
`pax-project` organization — not a project repo itself.

- The organization's profile page (what renders at
  [github.com/pax-project](https://github.com/pax-project)) is
  [`profile/README.md`](profile/README.md).
- Cross-cutting docs that don't belong to a single repo live in
  [`docs/ideas/`](docs/ideas/README.md) (the feature idea backlog).
- Every repo's spec, implementation-status, and build history lives in
  [`docs/goals/`](docs/goals/README.md) — kept out of `pax-core`/`lazy-pax`
  themselves so neither repo's own docs describe a moving target.
